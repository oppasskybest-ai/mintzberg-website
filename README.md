# mintzberg-website
Henry Mintzberg's personal website — Next.js rebuild

Read `mintzberg-master-prompt.md` and `mintzberg-addendum-final.md` (kept
outside this repo, in the project's chat/prompt history) before touching
anything here. `PROGRESS.md` in this repo is the running build log —
read it first every session.

## Local setup
```bash
npm install
cp .env.local.example .env.local   # fill in Supabase + Resend + admin secrets
npm run dev
```
